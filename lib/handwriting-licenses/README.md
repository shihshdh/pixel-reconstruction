# 手写诗句的数据来源

`lib/handwriting.generated.json` 由 `scripts/prepare-handwriting.py` 生成，笔画来自：

- **拉丁文字**：Sacramento 字体（© 2012 Brian J. Bonislawsky, Astigmatic），SIL Open Font License 1.1，见 `Sacramento-OFL.txt`。只使用由字形提取的笔画中心线，不分发字体文件本身。
- **汉字**：Make Me a Hanzi / hanzi-writer-data 的笔顺中线，源自 Arphic Technology 的字体，Arphic Public License，见 `ARPHICPL.TXT`。
- **日文**：KanjiVG（© Ulrich Apel），Creative Commons 署名-相同方式共享 3.0（CC BY-SA 3.0，https://creativecommons.org/licenses/by-sa/3.0/）。由其派生的笔画数据按同一许可提供。

诗句均为公有领域作品：杜甫、松尾芭蕉、Chairil Anwar、William Wordsworth、Charles Baudelaire、Walt Whitman、Alfred Tennyson、Paul Valéry。
